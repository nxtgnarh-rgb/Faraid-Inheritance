°General Questions

What is Faraid (Inheritance)?

Faraid (Inheritance) is a cross-platform application designed to automate and simplify Islamic inheritance (Ilm al-Faraid) calculations accurately across mobile and desktop devices.

Which languages does the application support?

The application supports multi-lingual switching globally, including English, Arabic, and Farsi.

How do I access the user manual or guide?

You can access the complete application guide directly from the settings or home interface via the built-in help panel.

•Jurisprudence & Calculations

Does the app support multiple schools of jurisprudence (Madhabs)?

Yes, you can select your preferred jurisprudence style—including Hanafi, Maliki, Shafi'i, Hanbali, or Shia Ja'fari—to ensure estate calculations match your specific traditional requirements.

How reliable are the calculations?

The application follows established Islamic inheritance computation frameworks tailored to the selected Madhab to ensure precise asset distribution.

•Pro License & Payments

What does the Pro version unlock?

Upgrading to Pro removes trial limitations and unlocks advanced features such as SMS-sharing capabilities and full PDF report generation tools.

How does SMS-sharing work in the Pro version?

Pro users gain access to direct SMS export functionality, allowing calculation reports to be sent seamlessly via text message, while free-tier users encounter automated warnings.

How do I activate my Pro license?

After completing a transaction via Paystack, enter your transaction reference code into the activation box on the home screen and click verify.

•Technical & Development

What engine is the app built with?

The application is built utilizing the Godot Engine for optimized multi-platform deployment.

Why is this repository private?

This repository is kept private to protect proprietary application logic, UI design implementations, and secure payment/backend integration parameters.
